# DAWTR3MSB
**Projecte: Entradas huevostyle**

Desenvolupador del projecte: **Marcos suarez**

## Objectiu del projecte
Plataforma de Venda d'Entrades per a un Esdeveniment d'Alta Demanda (Temps Real). Aquest sistema evita les col·lisions en les reserves i en la compra gràcies a l'ús d'una arquitectura orientada a events mitjançant Socket.IO i una font de veritat única liderada pel backend en Node.js.
